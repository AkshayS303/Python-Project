[2026-10-02] – Secure API Key via Environment Variable
-------------------------------------------------------
CHANGE: Moved the hardcoded Gemini API key out of source code and into the
        `.env` environment variable file using python-dotenv.

FILES MODIFIED:
  - ai_parser.py
      • Added `from dotenv import load_dotenv` import.
      • Added `load_dotenv()` call at module startup so the .env file is
        read before os.environ is accessed.
      • Changed DEFAULT_API_KEY fallback from a hardcoded string to an
        empty string — key MUST now come from GEMINI_API_KEY in .env.

  - requirements.txt
      • Added `python-dotenv>=1.0.0` dependency.

  - .gitignore
      • Added `.env`, `.env.*` (with `!.env.example` exception) to prevent
        the API key from being accidentally pushed to version control.

HOW IT WORKS:
  1. Developer creates / edits `.env` in the project root:
         GEMINI_API_KEY=<your-key-here>
  2. `load_dotenv()` at the top of ai_parser.py reads this file into the
     process environment before any other code runs.
  3. `os.environ.get("GEMINI_API_KEY", "")` picks up the value.
  4. The `.env` file is git-ignored, so the real key is never committed.

SECURITY IMPACT: High – eliminates credentials in source control.
