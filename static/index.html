    under the hood

    Four ways to crack a system.

    Pick your method. MatSolve runs the exact same deterministic engine every time — Gemini only handles the translation from words to equations.

    01

    Gaussian elimination

    AX = B → REF

    Forward elimination with partial pivoting, then back-substitution to pull out each variable.

    02

    Gauss-Jordan

    AX = B → RREF

    Pivots are normalised to 1 and eliminated in both directions, so the answer sits in the last column.

    03

    Cramer's rule

    xᵢ = det(Aᵢ) / det(A)

    Swaps the constant vector into each column and solves with determinants. Square systems only.

    04

    Matrix inversion

    X = A⁻¹B

    Checks det(A), builds the inverse and multiplies. Fast when the coefficient matrix is well behaved.

    Never offline-blocked. Word problems use Gemini with a cached/offline parser fallback, and direct matrices solve in-browser if the API is unreachable.
